## 📱 Grahak — QR Based Token System

Built during **HackByte 4.0 at IIITDM Jabalpur**, Grahak is a smart QR-based token management system designed for food vendors and crowded service environments.

### ✨ Features
- QR-based digital token generation
- Smart order tracking system
- Vendor management workflow
- Real-time queue handling
- Analytics dashboard for monitoring orders

### ⚙️ Tech Stack
`React Native` `React.js` `Node.js` `MongoDB`

### 🚀 Development Experience
Worked on frontend interfaces, workflow handling, responsive UI systems and improving user interaction for smooth order management and queue experience.
